LIMITATIONS AND REMAINING SCOPE
==================================================

Homework 3 implements gift card CRUD operations
using PHP, PDO, and SQLite.

Authentication, customer management, and gift
card redemption are not implemented as part
of this assignment.

The application uses server-side validation,
prepared statements, and output escaping.

Additional security features such as user
authorization and CSRF protection are not
implemented in this version.
